# Search Tool Selection（搜索工具选择）🔎

> **核心原则** ⚖️：搜索前必须先判定**需求类型**，再选择对应工具；不同需求用不同工具，禁止无脑混用；多源结论冲突时，以权威源 / 专业库为准 🔪。

## 工具清单（来源：`f:\BaiduSyncdisk\ZhengEnCi\Note\Resume\.trae\mcp.json`）🧰

- **MCP `dataPro_search`** 📚 — 专业数据统一检索入口（学术文献 / 工商 / 风险 / 金融 / 汽车 / 法律 / 司法）
- **MCP `web_search`** 🌐 — 联网搜索（网页 + 图片，支持时间范围 / 权威性 / 指定站点）
- **内建 `WebSearch`** 🔍 — 通用实时信息检索（兜底 / 交叉验证）
- **内建 `WebFetch`** 🕸️ — 抓取指定 URL 的正文内容

## 场景路由表（场景 → 首选工具 → 权重倾向）🎯

| 搜索场景 | 首选工具 | 权重倾向 |
|---|---|---|
| 学术文献（CNKI / 万方 / 维普）📚 | `dataPro_search` | 专业库优先 90% |
| 企业工商信息 / 企业风险 🏢 | `dataPro_search` | 专业库优先 90% |
| 股票金融 / 汽车配置 / 汽车销量 📈 | `dataPro_search` | 专业库优先 90% |
| 法律法规 / 司法案例 / 法律引用校验 ⚖️ | `dataPro_search` | 专业库优先 90% |
| 实时新闻 / 政策 / 热点 / 图片资讯 📰 | `web_search` | 联网优先 80% |
| 需权威性过滤 / 限定站点 / 限定时间范围 🌐 | `web_search` | 联网优先 85% |
| 通用事实 / 多源交叉验证 / 兜底 🔍 | 内建 `WebSearch` | 兜底 + 20% 校验 |
| 已有确定 URL，抓取正文 🕸️ | 内建 `WebFetch` | 指定抓取 |

## 工具使用约束 ⛓️

- **`dataPro_search`** 📚：一次只提**一个明确意图**；企业工商 / 风险支持 **1~5 家**；法律条文与司法案例必须**拆分查询**，不得混在一次 ❌
- **`web_search`** 🌐：`Query` 控制在 1~100 字符；要最近资讯加 `TimeRange`（OneDay / OneWeek / OneMonth / OneYear / 日期区间）；要权威源设 `AuthLevel=1`；限定站点用 `Sites`（≤20）；屏蔽站点用 `BlockHosts`（≤5）；图片检索用 `SearchType=image`
- **内建 `WebSearch`** 🔍：仅作通用实时信息与交叉验证的兜底，不承担专业结构化数据查询 🙅
- **内建 `WebFetch`** 🕸️：只用于已确定 URL 的正文抓取，不做站内漫游式检索

## 权重裁决原则 📌

- **专业结构化数据**（学术 / 工商 / 风险 / 金融 / 汽车 / 法律 / 司法）→ `dataPro_search` 优先，权重约 **90%** 🥇
- **实时网页资讯 / 需权威过滤 / 限定站点与时间**→ `web_search` 优先，权重约 **80%** 🥇
- **通用事实、多源交叉验证、前两者无合适结果**→ 内建 `WebSearch` 兜底 📉
- **多源冲突**时，专业库 / 权威源（`AuthLevel=1`、官方站点）优先采信 🔪
