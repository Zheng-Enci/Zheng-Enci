# Projects — 项目素材归档

## 概述
本目录按「项目」维度归档简历相关的项目素材，包括项目过程日志、开发记录与项目说明文档，用于简历撰写、面试复盘与技术积累。

## 子目录

- `AI坊学生管理系统/` — 厦门工学院人工智能创作坊学生管理系统（Vue3 + Spring Boot），按前端 / 后端、按月份归档开发日志。
- `mdconvert/` — 轻量级 Markdown 文档转换 Python 库（Markdown → HTML / PDF / DOCX），已在 PyPI 发布并在 GitHub / Gitee / GitCode 开源。
- `鼠标和键盘模拟项目/` — 基于 USB Gadget HID 协议的鼠标键盘模拟项目（FastAPI + RK3588），提供 RESTful API 控制鼠标移动与键盘输入。

## 项目文档（.md）

- `AI坊IP监控系统.md` — IP 地址监控与使用频率可视化系统（Flask + 原生前端），基于 ARP 扫描与热力图统计，解决手动分配 IP 冲突问题。
- `ROS全栈自主控制小车.md` — 基于中转服务器的 ROS 小车远程监控与控制（RDKx5 / Ubuntu），打通网页端到小车硬件的全链路通信。
- `三维重建全流程文件智慧管理系统.md` — 三维重建项目的流程管理、文件上传下载、权限控制与申述处理系统（Spring Boot 全栈）。
- `中科院城市环境高空摄像头多路图像拼接系统.md` — 中科院委托的多路视频流图像拼接系统（PyTorch + ResNet50 双分支回归网络，支持 4-5 张图片拼接）。
- `人力资源管理信息系统.md` — 企业人力资源管理系统（Spring Boot + MyBatis + Vue3），双角色，含考勤、工资、请假、留言板等模块。
- `人工智能创作坊_AI智慧监控系统.md` — AI 智慧监控系统项目日志（海康威视摄像机 + OpenCV 画面变化存储 + Vue3 / Spring Boot 全栈）。
- `红星农场玉米出芽监测系统（农科院项目）.md` — 农科院委托的玉米出芽率监测可视化系统（无人机航拍 + YOLO 检测 + Fabric.js 网格热力图），已在 Gitee 开源。
- `课堂异常行为检测系统_EduBot.md` — EduBot 课堂异常行为检测系统（YOLOv8n + 自研行为分类模型 + Flask 全栈 + 大模型教学辅助），含模型训练对比实验记录。
