# OldResume — 旧版简历素材

## 概述
本目录存放简历素材的历史版本，以时间轴方式记录个人的学历、证书、竞赛获奖、实习与项目经历，用于简历撰写与更新时取用。

## 文件说明

- `Resume.md` — **简历素材主版本**：以「时间轴表格 + 分节详述」结构记录个人完整经历，涵盖证书（全国计算机等级考试 NCRE Python 二级、工业和信息化人才岗位能力认证）、竞赛（第十五届蓝桥杯福建赛区 Python 程序设计大学 B 组三等奖）、实习（厦门弘尘网络科技有限公司）与项目经历（人力资源管理信息系统、课堂异常行为检测系统 EduBot、ROS 全栈自主控制小车等），含项目背景、目标、角色、职责、技术栈、成果与经验总结。
- `Resume_0.md` — **简历素材较早版本**：结构与主版本基本一致、条目略有精简的历史迭代稿。
- `Resume_1.md` — **近期项目记录片段**：仅保留 2025 年 10-12 月的项目记录（红星农场玉米出芽监测系统及其 Gitee 开源），为局部更新用的片段稿。
